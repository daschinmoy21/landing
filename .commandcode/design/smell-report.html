SMELL — Heuristic 9

Default type

Inter is the default sans-serif for 2024–2026 web projects. JetBrains Mono is the default monospace for developer tools. Together they’re the “safe default monospace tool” pairing. A project with the visual ambition of ASCII dithering, scanlines, and CLI-inspired cadence deserves a type choice with more character.

FIX: Keep JetBrains Mono (it earns its place) but replace Inter with something more editorial. /design typeset
